# AirPoint

A webcam‑based hand‑gesture mouse controller for Linux.

## Features
* Hand tracking with MediaPipe
* Cursor control, clicking, scrolling, swiping, and media play/pause via gestures
* Calibration for a custom active area
* One‑Euro filter for smooth cursor movement
* Relative (touchpad‑style) and absolute mapping modes
* Pause/resume functionality
* Logging to file and terminal
